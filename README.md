# CabralDesk — desktop portátil

> Public repository copy: this project starts without operational records or product-model seeds. Import your own Excel data in the application. Do not commit the `Dados` folder or real assistance records.

O programa abre o painel HTML em uma janela desktop. Inclui dashboard com chamados únicos e peças assistidas apresentados separadamente, análises por filial, análise por modelo, acompanhamento de chamados em aberto, cadastro, importação/exportação de Excel, impressão/PDF, cópia HTML independente e geração de apresentação PowerPoint. As tabelas de relatório exibem numeração. Os rankings mostram produtos por peças afetadas, motivos por chamados distintos e filiais por chamados distintos, custo total e prazo médio de atendimento; no prazo, cada chamado tem o mesmo peso, mesmo quando possui várias linhas.

A produção total da fábrica pode ser informada por período e data de referência. Os percentuais gerais comparam chamados ou peças com essa produção centralizada; o aplicativo não pede produção por filial. A aba **Produção por Produto** permite filtrar por ano inteiro ou por mês, ordenar a tabela por peças afetadas, incidência percentual ou nome e, opcionalmente, informar a produção de cada modelo no período selecionado. O gráfico percentual também pode ser ordenado por maior incidência, quantidade de peças ou nome; modelos sem produção informada não aparecem nele. A apresentação PowerPoint usa tema escuro, com números dos gráficos e tabelas ampliados, e explica os denominadores e as definições de chamado único, registro e peças.

Chart.js, SheetJS e PptxGenJS são fornecidos localmente; o painel não depende de CDN nem de conexão à internet. Os lançamentos, cadastros, quantidades de produção e preferências ficam no perfil WebView2 dentro de `Dados\PerfilWebView2`, ao lado do executável. Na primeira abertura, os dados embutidos no relatório são usados somente se ainda não houver dados locais. Atualizações do programa preservam o perfil existente; chaves de versões anteriores conhecidas são migradas sem apagar a origem.

**Ao atualizar:** feche o programa, substitua os arquivos do aplicativo e mantenha a pasta `Dados` existente no mesmo local. Não extraia um pacote de atualização por cima de uma pasta `Dados` que contenha informações importantes. Para proteção adicional, faça uma cópia de segurança dessa pasta antes da atualização. Apagar ou mover `Dados\PerfilWebView2` apaga ou separa os dados locais do perfil.

Para instalar, extraia o pacote para um local gravável e execute `CabralDesk.exe`. O Windows precisa ter o Microsoft Edge WebView2 Runtime. A importação de Excel substitui a base atual somente após confirmação no aplicativo. O botão **Salvar Cópia p/ Enviar (.html)** gera um relatório independente com os registros, cadastros e dados de produção atuais.
